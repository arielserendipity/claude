# 평균 탐구 활동 — 균형점 모델 × 막대 모델

초등학생이 **균형점 그림(저울: 추·받침점)**과 **막대 그림**을 오가며 평균을 스스로 발견하도록 돕는 AI 통합 웹 앱입니다.
학생 화면에는 제목이 **“활동 1”, “활동 2”**로만 보이고, 학생에게 가는 힌트는 **모두 그림 위의 시각 힌트**입니다(글 힌트 없음).

| 학생에게 보이는 이름 | 교사용 제목 |
| --- | --- |
| 활동 1 | 균형점 모델 예제 풀기 |
| 활동 2 | 균형점 모델과 막대 모델 연결하기 |

## 실행하기

**필요한 것:** Node.js 20 이상

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 등 입력 (없어도 실행됨)
npm run dev                  # http://localhost:3000
```

배포(한 서버에서 화면 + API):

```bash
npm run build
NODE_ENV=production npm start
```

AI 채점·진단은 `server.ts`가 서버에서 **Claude API**를 불러 처리합니다. API 키는 서버에만 있고 학생 브라우저로 나가지 않습니다.

### 환경 변수

| 이름 | 설명 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 서버에서만 쓰는 Claude API 키([console.anthropic.com](https://console.anthropic.com)에서 발급 — Claude.ai 구독과는 별도). 없으면 **규칙 기반 채점**으로 자동 전환되어 그대로 동작합니다. |
| `GRADER_CLAUDE_MODEL` | (선택) 쓸 Claude 모델. 기본값 `claude-opus-5-5`. |
| `GRADER_CLAUDE_EFFORT` | (선택) 생각의 깊이 `low`/`medium`/`high`/`xhigh`/`max`. 기본값 `medium` (학생이 결과를 기다리므로 빠른 쪽). |
| `VITE_TEACHER_PIN` | (선택) 교사용 대시보드(⚙️) PIN. 비워 두면 PIN 없이 열립니다. 학생이 우연히 여는 것을 막는 간단한 잠금이며 화면 코드에 포함되므로, 중요한 비밀번호는 쓰지 마세요. |
| `VITE_GOOGLE_SHEETS_URL` | (선택) 활동 기록을 받을 Google Apps Script 웹 앱 URL. 대시보드에서도 입력할 수 있습니다. |

## 활동 1 — 균형점 모델 예제 풀기

- 저울대(0~10) 위의 추는 고정되어 있고, 학생은 **받침점만** 끌어서 저울이 수평이 되는 곳을 찾습니다.
- [확인] 전에는 받침대가 저울을 붙잡고 있어 기울지 않습니다. [확인]을 누르면 받침대가 빠지고 저울이 실제로 기웁니다(바닥에 닿을 때까지만).
- 10단계. 단계를 통과하면 추가 1~2개씩 늘어나고, AI가 탐구 시간·조작 과정을 보고 다음 단계 난이도를 정합니다.
- **시각 힌트 (같은 단계에서 틀린 횟수에 따라)**
  - 2회: 각 추와 받침점 사이의 **거리 곡선**(왼쪽 파랑, 오른쪽 주황, 칸 수 표시)
  - 3회 이상: 여기에 **왼쪽 거리의 합 / 오른쪽 거리의 합 막대**까지 (받침점을 움직이면 실시간으로 바뀜)
  - 💡 버튼으로 켜고 끌 수 있습니다.
- 균형을 맞춘 문제는 활동 2에서 막대 그림으로 불러올 수 있습니다.

## 활동 2 — 균형점 모델과 막대 모델 연결하기

기본 자료: **2, 3, 4, 4, 6, 7, 9** (평균 5 · 모자란 양 3+2+1+1=7 · 넘친 양 1+2+4=7)

### 그림 도구

- **함께 보기**: 막대 그림과 균형점 그림을 나란히. 같은 자료는 같은 색·같은 이름표(가, 나, …)라서 막대/추를 누르면 짝이 함께 강조됩니다. 평균선을 위아래로 끌면 받침점이 같이 움직이고(반대도 마찬가지), 저울은 실시간으로 기웁니다.
- **바꿔 보기**: 슬라이더(또는 ▶)로 막대 그림이 균형점 그림으로 **변신**합니다.
  1. 막대 그림 전체가 90° 돌아 막대가 눕습니다.
  2. 막대가 끝(자료값)만 남기고 줄어듭니다 → 평균선과 막대 끝 사이의 칸만 남습니다.
  3. 막대 끝은 추가 되어 저울대로 떨어지고, 평균선은 받침점이 됩니다. 남은 칸은 **추와 받침점 사이의 거리**가 됩니다.
- **칸 보기** 버튼: 평균선보다 넘친 칸(주황 빗금)과 모자란 칸(파란 점선)을 두 그림 모두에 표시합니다.

### 서술형 문항

| 번호 | 문항 |
| --- | --- |
| 1 | 막대 그림의 평균 5와 균형점 그림의 평균 5는 각각 무엇으로 나타나나요? |
| 2-1 | 9인 막대에서 5보다 넘친 4칸은 균형점 그림의 어디에 해당하나요? |
| 2-2 | 반대로, 2의 추와 받침점 5 사이의 3칸은 막대 그림의 어디인가요? |
| 3-1 | 막대 그림에서 ‘모자란 양과 넘친 양이 같다’는 설명은 균형점 그림에서는 어떻게 표현되나요? 왜 같은 관계인가요? |
| 3-2 | 반대로, 균형점 그림에서 ‘받침점 왼쪽 추들의 거리의 합과 오른쪽 추들의 거리의 합이 같다’는 설명은 막대 그림에서는 어떻게 표현되나요? 왜 같은 관계인가요? |
| 4 | (더 나아가기) 자료를 바꾸거나 활동 1 문제를 불러와서 같은 관계가 있는지 살펴보고 쓰기 |

- 문항은 하나씩 열립니다(앞 문항을 한 번 제출하면 다음 문항이 열림). 3-2는 3-1의 답을 담고 있어서 3-1 제출 뒤에만 보입니다.
- 3-2를 제출하면 **자료 바꾸기**가 열립니다: 막대 높이/추 위치를 끌어 바꾸기, ➕➖로 자료 수 바꾸기, 활동 1에서 푼 문제 불러오기.

### AI 평가 → 학생에게는 아이콘 + 시각 힌트만

서버(`/api/evaluate-answer`)가 문항별 **핵심 아이디어**가 답에 들어 있는지 판단합니다(Claude, 키가 없거나 호출이 실패·거절되면 규칙 채점).

- 학생 화면: ⭐ 통과 · 반쪽 별 부분 · 🔍 다시 — 그리고 **빠진 아이디어에 맞는 시각 힌트가 그림 위에서 자동 재생**(💡 버튼으로 다시 보기).
- 교사 화면: 학생 답, 판정, AI의 글 진단(이해한 점·빠진 점·오개념·지도 제안).

| 빠진 아이디어 | 자동 시각 힌트 |
| --- | --- |
| 평균선 / 받침점 (1) | 평균선과 받침점이 함께 빛나고 화살표로 연결 |
| 넘친 4칸 = 9의 추–받침점 거리 (2-1) | 9 막대의 넘친 칸과 저울 위 거리(주황)를 강조·연결, 칸 수 표시 |
| 3칸 = 2 막대 위 모자란 칸 (2-2) | 저울 위 거리(파랑)와 2 막대 위 빈칸을 강조·연결 |
| 왼쪽 거리 합 = 오른쪽 거리 합 (3-1, 4) | 왼쪽 거리들과 오른쪽 거리들이 각각 한 줄로 모여 길이 비교 (7 = 7) |
| 넘친 칸 합 = 모자란 칸 합 (3-2, 4) | 넘친 칸이 날아가 모자란 칸을 채워 모든 막대가 평균 높이로 고르게 됨 |
| 칸 = 거리인 이유 (3-1, 3-2) | ‘바꿔 보기’ 변신이 자동 재생되며 칸이 거리로 바뀌는 과정을 보여 줌 |

문항·예시 답안·채점 기준·힌트 연결은 모두 [`lib/questions.ts`](lib/questions.ts) 한 곳에서 고칩니다(서버와 화면이 같은 파일을 씀).

## 교사용 대시보드 (⚙️)

- 활동 구성(교사용 제목), 문항별 예시 답안·채점 기준·자동 힌트 표
- **AI 분석 기록**: 학생별 제출 답안, 판정, AI 진단(활동 1의 단계별 탐구 진단 포함)
- **Google 스프레드시트 연동**: 표시된 Apps Script 코드를 시트에 배포하고 URL을 넣으면 모든 활동 기록이 실시간으로 쌓입니다.
- 활동 로그 CSV 내려받기, 이 기기 기록 지우기

학생 답과 기록은 기기 브라우저(localStorage)에도 저장되어 새로고침해도 이어서 할 수 있습니다.

