# 평균 탐구 활동 — 균형점 모델 × 막대 모델

초등학생이 **균형점 그림(저울: 추·받침점)**과 **막대 그림**을 오가며 평균을 스스로 발견하도록 돕는 AI 통합 웹 앱입니다.
학생 화면에는 제목이 **“활동 1”, “활동 2”**로만 보이고, 학생에게 가는 힌트는 **모두 그림 위의 시각 힌트**입니다(글 힌트 없음).

| 학생에게 보이는 이름 | 교사용 제목 |
| --- | --- |
| 활동 1 | 균형점 모델 예제 풀기 |
| 활동 2 | 균형점 모델과 막대 모델 연결하기 |

## 실행하기

**필요한 것:** Node.js 20 이상

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 등 입력 (없어도 실행됨)
npm run dev                  # http://localhost:3000
```

배포(한 서버에서 화면 + API):

```bash
npm run build
NODE_ENV=production npm start
```

활동 2의 서술형 채점은 `server.ts`가 서버에서 **Claude API**를 불러 처리합니다. API 키는 서버에만 있고 학생 브라우저로 나가지 않습니다. 활동 1은 학생이 기다리지 않도록 AI 없이 규칙으로 바로 진단합니다.

### 학생 태블릿으로 쓰기 (Render 무료 배포)

학생마다 자기 태블릿으로 들어오려면 인터넷 주소가 있는 서버에 올려야 합니다. 이 저장소에는 [Render](https://render.com) 설정 파일(`render.yaml`)이 들어 있어서 아래 순서만 따르면 됩니다.

1. **코드 합치기**: GitHub의 PR 페이지에서 초록색 **Merge pull request** → **Confirm merge**를 누릅니다. (Render는 `main` 브랜치를 올립니다.)
2. **Render 가입**: render.com에서 **GitHub 계정으로 가입**합니다.
3. **배포 만들기**: 대시보드 **New** → **Blueprint** → 이 저장소를 고릅니다. 입력 칸이 나오면:
   - `ANTHROPIC_API_KEY`: Claude API 키 (채팅이나 GitHub에는 절대 붙여 넣지 마세요)
   - `VITE_TEACHER_PIN`: 교사용 대시보드 잠금 번호 (예: 네 자리 숫자) — 학생 태블릿에서 ⚙️를 눌러도 못 열게
   - `VITE_GOOGLE_SHEETS_URL`: 비워 두어도 됩니다 (아래 5번)
   - **Apply**를 누르고 3~5분 기다리면 `https://average-activity-xxxx.onrender.com` 같은 주소가 생깁니다.
4. **학생에게 주소 알려 주기**: 칠판에 적거나 QR 코드로 나눠 줍니다. 무료 요금제는 15분 동안 아무도 안 쓰면 잠들어서 첫 접속에 1분쯤 걸리니, **수업 몇 분 전에 선생님이 먼저 한 번 열어** 두세요.
5. **모든 학생 결과를 한곳에서 보기** (선택): 학생 기록은 각 태블릿에 따로 저장되므로, 한꺼번에 보려면 구글 시트를 연결합니다. 앱의 ⚙️ 교사용 대시보드에 있는 Apps Script 코드를 구글 시트([확장 프로그램] → [Apps Script])에 붙여넣고 웹 앱으로 배포한 뒤, 받은 URL을 Render의 **Environment** 화면에서 `VITE_GOOGLE_SHEETS_URL`에 넣고 **Manual Deploy**를 누릅니다. 그러면 모든 태블릿의 답안·AI 분석이 시트에 한 줄씩 쌓입니다.

요금 관리:
- Claude는 **활동 2 서술형 답을 제출할 때만** 부릅니다(활동 1은 호출 없음). 호출은 기본으로 **분당 120회, 하루 1000회**까지만 하고, 넘으면 자동으로 규칙 채점으로 대신합니다(`GRADER_MAX_CALLS_PER_MINUTE`, `GRADER_MAX_CALLS_PER_DAY`로 조정).
- Anthropic Console의 사용 한도(Limits) 메뉴에서 **월 사용 한도**도 걸어 두기를 권합니다.
- 키를 바꿀 때는 Render → 서비스 → **Environment**에서 `ANTHROPIC_API_KEY`만 고쳐 저장하면 됩니다.

### 환경 변수

| 이름 | 설명 |
| --- | --- |
| `ANTHROPIC_API_KEY` | 서버에서만 쓰는 Claude API 키([console.anthropic.com](https://console.anthropic.com)에서 발급 — Claude.ai 구독과는 별도). 없으면 **규칙 기반 채점**으로 자동 전환되어 그대로 동작합니다. |

| `GRADER_CLAUDE_EFFORT` | (선택) 생각의 깊이 `low`/`medium`/`high`/`xhigh`/`max`. 기본값 `medium` (학생이 결과를 기다리므로 빠른 쪽). |
| `GRADER_MAX_CALLS_PER_MINUTE` / `GRADER_MAX_CALLS_PER_DAY` | (선택) Claude 호출 상한. 기본 분당 120회 / 하루 1000회. 넘으면 규칙 채점으로 대신합니다. |
| `VITE_TEACHER_CODE` | (선택) 교사 미리보기 코드. 기본값 `math2026` (아래 ‘교사 미리보기’ 참고). |
| `VITE_TEACHER_PIN` | (선택) 교사용 대시보드(⚙️) PIN. 비워 두면 PIN 없이 열립니다. 학생이 우연히 여는 것을 막는 간단한 잠금이며 화면 코드에 포함되므로, 중요한 비밀번호는 쓰지 마세요. |
| `VITE_GOOGLE_SHEETS_URL` | (선택) 활동 기록을 받을 Google Apps Script 웹 앱 URL. 대시보드에서도 입력할 수 있습니다. |

## 활동 1 — 균형점 모델 예제 풀기

- 저울대(0~10) 위의 추는 고정되어 있고, 학생은 **받침점만** 끌어서 저울이 수평이 되는 곳을 찾습니다.
- [확인] 전에는 받침대가 저울을 붙잡고 있어 기울지 않습니다. [확인]을 누르면 받침대가 빠지고 저울이 실제로 기웁니다(바닥에 닿을 때까지만).
- 10단계. 단계를 통과하면 추가 1~2개씩 늘어납니다. [확인]을 누르면 AI를 기다리지 않고 규칙([`lib/activity1Rules.ts`](lib/activity1Rules.ts))으로 바로 판단합니다.
  - 난이도: 한 번에 20초 안에 풀면 추 2개, 아니면 1개를 더함. 5단계부터 한 번에 풀면 평균이 0.5 단위인 문제도 나옴.
  - 교사용 진단: 탐구 시간, 받침점을 옮긴 횟수·방향 바꿈, 평균과의 차이, 그리고 자주 보이는 오개념(가장 왼쪽·오른쪽 추의 한가운데나 가운데 놓인 추를 균형점으로 생각함)을 기록.
- **시각 힌트 (같은 단계에서 틀린 횟수에 따라)**
  - 2회: 각 추와 받침점 사이의 **거리 곡선**(왼쪽 파랑, 오른쪽 주황, 칸 수 표시)
  - 3회 이상: 여기에 **왼쪽 거리의 합 / 오른쪽 거리의 합 막대**까지 (받침점을 움직이면 실시간으로 바뀜)
  - 💡 버튼으로 켜고 끌 수 있습니다.
- 균형을 맞춘 문제는 활동 2에서 막대 그림으로 불러올 수 있습니다.

## 활동 2 — 균형점 모델과 막대 모델 연결하기

기본 자료: **2, 3, 4, 4, 6, 7, 9** (평균 5 · 모자란 양 3+2+1+1=7 · 넘친 양 1+2+4=7)

### 그림 도구

- **초록색**: 두 그림에서 함께 움직이는 초록 표시입니다. 막대 그림에서는 **평균선(초록 선)**, 균형점 그림에서는 **받침점(초록 세모)**이고, 둘 다 같은 초록 동그라미(위치 숫자)를 달고 있습니다. 문항에서는 두 그림에 함께 하는 조작은 ‘초록색’, 한 그림에 대한 발문은 ‘평균선’ 또는 ‘받침점’으로만 씁니다(활동 1의 받침점도 같은 초록 세모·초록 동그라미).
- **함께 보기**: 막대 그림과 균형점 그림을 나란히. 같은 자료는 같은 색·같은 이름표(가, 나, …)라서 막대/추를 누르면 짝이 함께 강조됩니다. 초록색을 끌면(막대 그림에서는 위아래, 균형점 그림에서는 좌우) 두 그림의 초록색이 같이 움직이고, 저울은 실시간으로 기웁니다.
- **바꿔 보기**: 슬라이더(또는 ▶)로 막대 그림이 균형점 그림으로 **변신**합니다.
  1. 막대 그림 전체가 90° 돌아 막대가 눕습니다.
  2. 막대가 끝(자료값)만 남기고 줄어듭니다 → 평균선과 막대 끝 사이의 칸만 남습니다.
  3. 막대 끝은 추가 되어 저울대로 떨어지고, 평균선은 받침점이 됩니다. 남은 칸은 **추와 받침점 사이의 거리**가 됩니다.
- **칸 보기** 버튼: 평균선보다 넘친 칸(주황 빗금)과 모자란 칸(파란 점선)을 두 그림 모두에 표시합니다.

### 서술형 문항 (발문 + 그림별 답 칸)

문항마다 먼저 그림에서 해 볼 일을 안내하는 **첫 발문**이 있습니다. 첫 발문은 **막대 그림과 균형점 그림에 똑같이 적용되는 하나의 과제**입니다(예: “9가 평균보다 얼마나 큰지가 두 그림에서 각각 어떻게 나타나는지 찾아보세요”).
답은 모든 문항에서 **📊 막대 그림에서 / ⚖️ 균형점 그림에서 / 🔗 두 그림을 이어 보면** 세 칸에 나누어 씁니다. 막대 그림 칸과 균형점 그림 칸의 발문은 **같은 틀**로 묻고(그림 이름과 대상만 바뀜), 같은 수가 각 그림에서 **무엇을 뜻하는지** 쓰게 합니다.
평가하듯 묻지 않고, 그림을 조작하며 스스로 알아내도록 이끄는 발문으로 묻습니다.

| 번호 | 첫 발문 (두 그림 공통) | 📊 막대 그림에서 | ⚖️ 균형점 그림에서 | 🔗 두 그림을 이어 보면 |
| --- | --- | --- | --- | --- |
| 1 | 초록색(평균선 = 받침점)을 소개하고, 평균을 구해 초록색을 평균에 놓았을 때 두 그림이 각각 어떻게 되는지 살펴보기 (3에서 시작) | 초록색이 평균에 있을 때 막대 그림은? 평균은 무슨 뜻? → **막대들을 고르게 한 높이** | 초록색이 평균에 있을 때 균형점 그림은? 평균은 무슨 뜻? → **저울이 수평이 되는 자리** | 두 뜻을 함께 생각하면 평균은 어떤 수? → **고르게 한 높이이면서 수평이 되는 자리** |
| 2-1 | 9가 평균보다 얼마나 큰지가 두 그림에서 각각 어떻게 나타나는지 | 9인 막대의 끝은 평균선에서 어느 쪽으로 몇 칸? 무슨 뜻? → 위로 4칸, **평균보다 4 크다** | 9의 추는 받침점에서 어느 쪽으로 몇 칸? 무슨 뜻? → 오른쪽 4칸, **평균보다 4 크다** | 넘친 칸은 무엇이 되나요? → **추와 받침점 사이 거리** |
| 2-2 | 2가 평균보다 얼마나 작은지가 두 그림에서 각각 어떻게 나타나는지 | 2인 막대의 끝은 어느 쪽으로 몇 칸? 무슨 뜻? → 아래로 3칸, **평균보다 3 작다** | 2의 추는 어느 쪽으로 몇 칸? 무슨 뜻? → 왼쪽 3칸, **평균보다 3 작다** | 평균선 위·아래는 받침점의 어느 쪽이 되나요? → **위는 오른쪽, 아래는 왼쪽** |
| 3-1 | 초록색을 평균에 두고 ‘칸’ 버튼을 눌러 평균보다 큰 쪽과 작은 쪽을 두 그림에서 각각 모두 세기 | 넘친 칸 합, 모자란 칸 합 → 7, 7 | 오른쪽 거리 합, 왼쪽 거리 합 → 7, 7 | 어떤 합끼리 같은 것을 나타내나요? → **넘친 칸 합 = 오른쪽 거리 합, 모자란 칸 합 = 왼쪽 거리 합** |
| 3-2 | 두 합이 같다는 것이 두 그림에서 각각 무엇을 뜻하는지 | 넘친 칸 합 = 모자란 칸 합이면 막대들은? → **모두 5로 고르게 된다** | 오른쪽 거리 합 = 왼쪽 거리 합이면 저울은? → **수평이 된다** | 두 그림에서 일어난 일은 어떤 관계? → **같은 뜻(넘친 칸 = 오른쪽 거리, 모자란 칸 = 왼쪽 거리)** |
| 4 | (더 나아가기) 나만의 자료로 1~3번을 두 그림에서 각각 다시 확인하기 | 내 자료와 평균, 초록색을 평균에 두었을 때 넘친·모자란 칸의 합 | 초록색을 평균에 두었을 때 저울은?, 오른쪽·왼쪽 거리의 합 | 자료가 바뀌어도 똑같이 나타나는 것 |

- 칸마다 제출하면 ✓(초록)가 붙어 어느 그림에 대한 설명이 빠졌는지 알 수 있습니다. 모든 칸 ✓ = ⭐, 일부 = 반쪽 별, 하나도 없음 = 🔍.
- 채점은 **칸별로** 합니다. 각 칸은 그 칸에 쓴 글로만 판단하므로, 막대 그림 칸에는 막대 그림의 뜻을, 균형점 그림 칸에는 균형점 그림의 뜻을 써야 합니다.
- ‘무엇을 뜻할까요?’를 묻는 칸은 수만 쓰면(예: “4칸”) 인정하지 않고, 뜻(예: “평균보다 4 크다”, “고르게 한 높이”, “수평이 되는 곳”)이 있어야 인정합니다. 수를 묻는 칸은 수가 맞아야 인정합니다.
- 채점은 너그럽게 합니다. 서툰 표현·다른 낱말(초록 선, 초록 세모, 가로줄, 세모 등)·짧은 답도 핵심 뜻이 맞으면 인정하고, 애매하면 인정하는 쪽으로 봅니다. ‘모르겠어요’ 같은 답은 AI를 부르지 않고 바로 🔍입니다.
- 문항은 하나씩 열립니다. 앞 문항에서 **반쪽 별 이상**을 받아야 다음 문항이 열리고, ‘모르겠어요’처럼 핵심 내용이 하나도 없는 답(🔍)으로는 넘어갈 수 없습니다. 
- 새 문항을 열면 그림은 힌트 없이 깨끗한 처음 상태(함께 보기, 초록색 5 — 1번만 3)에서 시작합니다.
- **4번 문항**을 열면 그림 오른쪽 위에 **[처음 자료] [새로운 자료]**가 나타납니다. ‘새로운 자료’에서는:
  - 막대 그림 끝의 점선 **‘+’ 자리를 누르면 누른 높이로 막대**가 생깁니다. 막대 윗부분을 끌어 높이를 바꾸고, 아래 **×**로 지웁니다.
  - 균형점 그림 저울대 위의 **점선 추를 누르면 그 자리에 추**가 놓입니다. 추를 끌어 옮기고, 추를 누르면 나오는 **×**로 지웁니다.
  - 두 그림은 늘 같은 자료라서 한쪽에 놓으면 다른 쪽에도 바로 생깁니다. 활동 1에서 푼 문제 불러오기, 🗑 모두 지우기도 있습니다.

### AI 평가 → 학생에게는 아이콘 + 시각 힌트만

서버(`/api/evaluate-answer`)가 문항별 **핵심 아이디어**가 답에 들어 있는지 판단합니다(Claude, 키가 없거나 호출이 실패·거절되면 규칙 채점).

- 학생 화면: ⭐ 통과 · 반쪽 별 부분 · 🔍 다시. 같은 문항에서 **🔍를 2번 이상 받은 뒤부터** 빠진 칸에 맞는 **시각 힌트가 그림 위에서 자동 재생**됩니다(💡 버튼으로 다시 보기). 그 전에는 힌트 없이 스스로 생각하게 합니다.
- 교사 화면: 학생 답, 판정, AI의 글 진단(이해한 점·빠진 점·오개념·지도 제안).

| 빠진 칸 | 자동 시각 힌트 |
| --- | --- |
| 1 균형점 그림·이어 보기, 4 균형점 그림 | 평균선과 받침점이 함께 빛나고 화살표로 연결 |
| 1 막대 그림, 3-1·3-2·4 막대 그림 | 넘친 칸이 날아가 모자란 칸을 채워 모든 막대가 평균 높이로 고르게 됨 |
| 2-1 막대·균형점 그림 | 9 막대의 넘친 칸과 저울 위 거리(주황)를 강조·연결, 칸 수 표시 |
| 2-2 막대·균형점 그림 | 저울 위 거리(파랑)와 2 막대 위 빈칸을 강조·연결 |
| 3-1·3-2 균형점 그림, 4 이어 보기 | 왼쪽 거리들과 오른쪽 거리들이 각각 한 줄로 모여 길이 비교 (7 = 7) |
| 2-1·2-2·3-1·3-2 이어 보기 | ‘바꿔 보기’ 변신이 자동 재생되며 칸이 거리로 바뀌는 과정을 보여 줌 |

문항·예시 답안·채점 기준·힌트 연결은 모두 [`lib/questions.ts`](lib/questions.ts) 한 곳에서 고칩니다(서버와 화면이 같은 파일을 씀).

## 교사 미리보기 (이름: `math2026`)

첫 화면 이름 칸에 **`math2026`**을 넣고 들어가면 교사 미리보기가 켜집니다(상단에 ‘교사 미리보기’ 표시).

- 활동 2: 답을 쓰지 않아도 **모든 문항과 4번 자료 만들기가 열려** 있고, 각 문항의 **‘교사: 힌트 미리보기’**로 그 문항의 시각 힌트를 모두 볼 수 있습니다.
- 활동 1: **‘교사: 다음 단계’**로 단계를 건너뛸 수 있고, 💡 힌트(거리 곡선·거리의 합)를 처음부터 켜 볼 수 있습니다.
- 코드는 `VITE_TEACHER_CODE`로 바꿀 수 있습니다. 화면 코드에 들어 있는 간단한 코드이므로 비밀번호로 쓰지는 마세요.

## 교사용 대시보드 (⚙️)

오른쪽 위 ⚙️는 **교사 미리보기(이름 `math2026`)로 들어왔을 때만** 보입니다. 학생 화면에는 나타나지 않습니다. 학생 태블릿의 기록을 보려면 그 태블릿 첫 화면에서 이름을 `math2026`으로 바꾸면 됩니다(그 기기의 기록은 그대로 남아 있음).

- 활동 구성(교사용 제목), 문항별 예시 답안·채점 기준·자동 힌트 표
- **분석 기록**: 활동 2 학생별 제출 답안·판정·AI 진단, 활동 1 단계별 규칙 진단
- **Google 스프레드시트 연동**: 표시된 Apps Script 코드를 시트에 배포하고 URL을 넣으면 모든 활동 기록이 실시간으로 쌓입니다.
- 활동 로그 CSV 내려받기, 이 기기 기록 지우기

학생 답과 기록은 기기 브라우저(localStorage)에도 저장되어 새로고침해도 이어서 할 수 있습니다.
